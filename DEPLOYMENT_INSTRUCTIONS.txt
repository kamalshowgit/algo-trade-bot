                              QUICK START (10 STEPS)
================================================================================

STEP 1: Prepare Ubuntu Server
  □ SSH into your Ubuntu/EC2 server
  □ Run: sudo apt update && sudo apt upgrade -y
  □ Install: sudo apt install -y python3 python3-pip python3-venv git nodejs
  □ Install PM2: sudo npm install -g pm2

STEP 2: Clone Your Project
  □ cd ~
  □ git clone https://github.com/YOUR_USERNAME/algo-trade-bot trading_bot
  □ OR: scp -r ~/Desktop/Work/algo-trade/algo-trade-bot/* user@server:~/trading_bot/

STEP 3: Copy Credentials
  □ cd ~/trading_bot
  □ cp .env.example .env
  □ Edit .env with your credentials:
    - ANGEL_API_KEY=your_key
    - ANGEL_CLIENT_ID=your_id
    - ANGEL_PASSWORD=your_password
    - ANGEL_TOTP_SECRET=your_secret
    - EMAIL_SENDER=your_gmail@gmail.com
    - EMAIL_PASSWORD=your_app_password
    - RECIPIENT_EMAIL=email1@gmail.com,email2@gmail.com

STEP 4: Deploy with Automation
  □ bash deploy_and_start.sh
  □ Wait for completion (2-3 minutes)

STEP 5: Verify Installation
  □ bash health_check.sh
  □ Should show all ✅ checks passing

STEP 6: Deploy with PM2
  □ pm2 start ecosystem.config.js
  □ pm2 status (should show "stopped" = normal)

STEP 7: Save PM2 Config
  □ pm2 save
  □ pm2 startup
  □ Copy command shown and run with sudo

STEP 8: Test Manually (Optional)
  □ python3 main.py
  □ Should show backtest results with all 4 strategies

STEP 9: Send Test Email
  □ python3 -c "from send_email_report import send_email; send_email()"
  □ Check inbox for email with strategy comparison

STEP 10: Monitor
  □ pm2 logs HFT_Bot (show real-time logs)
  □ bash status_check.sh (quick status)
  □ bash troubleshoot.sh (full diagnostics)

                         WHAT HAPPENS AFTER DEPLOYMENT
================================================================================

  Status: Bot is "stopped" (0 PID, 0% CPU)

  PM2 automatically starts bot via cron_restart
  Bot fetches market data (2000+ 5-minute candles)
  4 strategies run in parallel on same price data

DURING 9:15 AM - 3:15 PM IST:
  All 4 strategies generate trades
  Results saved: strategy_[1-4]_backtest_results.csv
  Continuous monitoring and logging

AT 3:15 PM IST:
  Market closes
  Bot exits gracefully
  Results calculated and compared

AT 3:20 PM IST:
  PM2 cron_stop triggers
  Bot "stops" (ready for next day)
  Email report sent with:
    • Strategy comparison table
    • Best strategy highlighted (🏆)
    • Top 5 trades
    • CSV attachments

NEXT DAY AT 9:15 AM:
  Process repeats automatically

================================================================================
                         TROUBLESHOOTING QUICK REFERENCE
================================================================================

❌ "No intraday data available"
   ✅ NORMAL - runs only 9:15 AM - 3:15 PM IST

❌ PM2 shows "stopped" status
   ✅ NORMAL - bot stops after market close, starts at 9:15 AM

❌ Email not received
   1. Check .env has correct Gmail app password
   2. Run: bash troubleshoot.sh
   3. Check spam/promotions folder
   4. Manual test: python3 -c "from send_email_report import send_email; send_email()"

❌ Module not found error
   1. source venv/bin/activate
   2. pip install -r requirements.txt
   3. bash troubleshoot.sh

❌ Bot doesn't start at 9:15 AM
   1. timedatectl (verify timezone is Asia/Kolkata for IST)
   2. grep cron_ ecosystem.config.js (verify cron settings)
   3. pm2 restart HFT_Bot
   4. pm2 logs (check logs)
